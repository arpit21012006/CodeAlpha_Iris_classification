# 🌸 IrisVision — Iris Flower Classification

An interactive Machine Learning dashboard built using Python,
Scikit-learn, Streamlit and Plotly as part of the
CodeAlpha Data Science Internship.

## 🔗 GitHub Repository

https://github.com/arpit21012006/CodeAlpha_Iris_Classification

## 📌 Project Overview

IrisVision is a machine learning application that predicts
Iris flower species using four botanical measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The model classifies flowers into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## ✨ Key Features

- Interactive flower species prediction
- Random Forest Classifier
- Logistic Regression model comparison
- Prediction confidence visualization
- Species distribution analysis
- Interactive scatter plots and box plots
- Feature correlation heatmap
- Accuracy, Precision, Recall and F1-score
- Confusion matrix visualization
- Dataset explorer with CSV download
- Responsive dark-themed Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- HTML/CSS

## 📊 Dataset

The project uses the Iris flower dataset containing
150 observations across three flower species.

Dataset file: `Iris.csv`

## 🚀 Installation and Usage

Clone the repository:

git clone https://github.com/arpit21012006/CodeAlpha_Iris_Classification.git

Navigate to the project folder:

cd CodeAlpha_Iris_Classification

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py

Open the local URL displayed in your terminal.

## 🧠 Machine Learning Workflow

1. Load and clean the dataset.
2. Encode flower species labels.
3. Split data into training and testing sets.
4. Apply feature scaling for Logistic Regression.
5. Train classification models.
6. Evaluate model performance.
7. Predict species from user-provided measurements.
